# 原作 POV-Ray 渲染源文件

来自 M. Weber 的 Helicoidal Karcher-Scherk 页面（POV-Ray Sources），按参数分文件夹：`k{k}-a{a}`。

每个文件夹：
- `mathematica.pov`：场景文件（相机、灯光、配色、物体旋转）
- `dummy.pov.zip`：Mathematica 导出的网格（解压后是 `dummy.pov`，被场景文件 include）
- `mathematica.png`：原作渲染图（k8 两组是 `mathematica-1/-2.png`）

全部为 3 个周期；翼长 xmax：k ≤ 5 为 6.3，k = 8 为 5（由网格拟合，见上一级 README）。
