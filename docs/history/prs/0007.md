## 说明 · Description

**01 · Growth simulator** in the workspace: the incubator's Growth Simulator, drawn on the real OSM map at its true position, as the workspace's first simulation.

Builds on [PR-0005](0005.md) (incubator split) and [PR-0006](0006.md) (renumbering); this branch contains both, so merge those first (or merge this one and the two close as merged).

### What it does
- **Nav `01`**, right after `00 伦敦地图`; opens at any level. The timeline becomes the years 2025–2100 (7 years/s, as the incubator). Leaving it keeps the growth as a background on the other levels (switch in the panel).
- **On the OSM map** (MapLibre): one WebGL custom layer. Each 50 m parcel is 4 bytes (`cells.js`), uploaded once per run; the year is a uniform, so playback costs nothing per frame. Drawn under labels, under the workspace's roads and 3D buildings. At ≥ 6 px per parcel each 50 m parcel gets an outline. Rails and stations are MapLibre line/circle layers. Canvas fallback draws in EPSG:27700.
- **Panel**: the same controls as the incubator page — mode, Run variation, the 11 simple controls, Advanced settings (all 23, presets, red stretches), readout, Against the final + note, display switches. Engine and comparison run in a worker.

### One source with the incubator
The module keeps **no copy** of the simulator: at run time it fetches `incubator/growth-simulator-dark/{engine.js, controls.js, data/…}` (fetch, not import — isolation check passes). Change the incubator and the workspace follows. `tests/module.test.mjs` guards the link (engine API, every setting has a slider, simple controls round-trip, data layout). Frozen releases read the live incubator.

### Position
Grid is EPSG:27700; drawn through a 60 × 50 mesh whose vertices are projected exactly by `shared/geo-core` (OS TM + Helmert, ~2–5 m). Interpolation error inside the mesh < 1 m (tested). A four-corner stretch would be off by ~280 m.
