## 说明 · Description

打开「城市生长模拟」每次都要重新下载约 13 MB 的问题。

**原因**：上一个修复（[PR-0023](0023.md)）给从孵化区读取的文件加上了「部署版本号」，这样确实不会再新旧混用，但副作用是：只要仓库有任何一次部署（包括 tensor-studio 等其他 app 的提交），版本号就变，浏览器就把 01 的数据全部重新下载一遍：最终结果 4.3 MB，以及后台的地面数据 8.4 MB。

**修复**：`tools/build-site.mjs` 在部署时给孵化区的每个文件算一个内容哈希，写进 `growth.js`；页面和后台线程读取文件时带上这个哈希。文件内容没变，地址就不变，浏览器直接用缓存；文件改了，地址才变，也不会混用旧文件。

测试：`node --test` 57 项全部通过；已在 Chrome 中验证：模块打开正常，「算吸引力」的磁力场正常。
