## 说明 · Description

## 问题
从伦敦地图进入张量场工作室时，工作室嵌在地图的 iframe 里面（第二层），主程序的 embed 桥只处理第一层：
- 工作室自带的「中文 / English」开关没有被隐藏
- 主程序切换语言时，工作室不会跟着变
- 点「保留绕开 / 清除重建」重载后，会回到打开时的语言

## 改动
- `app/appview.js`：监听被嵌入的页面里新出现的 iframe，按地址匹配 `catalogue.json` 里的 app，套用同一套 embed 配置：页面一开始就隐藏它的开关，加载时和每次切换语言时推送语言，每次重载都重新处理。
- `embed` 新增可选字段 `hostLang`：app 从父窗口读取起始语言的属性路径。张量场工作室是 `__TENSOR_SITE_INPUT__.lang`，所以重建后语言保持不变。
- `app/catalogue.js` 增加 `items()`；`app/main.js` 把它交给 appview。
- `incubator/catalogue.json`：给 tensor-studio 加上 `hostLang`。

孵化器里的地图和工作室本身没有改动，单独打开时仍然有自己的开关。

## 测试
- `node --test` 57 项全部通过，模块隔离检查通过
