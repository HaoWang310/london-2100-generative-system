## 说明 · Description

Each step card now ends with two buttons instead of one. Play analysis runs that step's generation animation and stops; Next skips the animation, shows the step's result and opens the next card. The last card's button reads Finish and leaves the demo for the free 3D view.

Cards that are not yet reachable are greyed out. Changing a parameter in an already generated step rolls the picture back to that step. Button clicks made while a recompute is running are no longer ignored or overwritten.

Checked by clicking through the 2D flow in headless Chrome with a stand-in for three.js; the real 3D transition was not run here.
