## 说明 · Description

- **A new standalone incubator app, `incubator/loop-city-real-map/`:** the real OpenStreetMap city round London with the project's data layers, dark and light, in plan and in 3D. It is the base map only; nothing runs or grows on it, so it can be combined with the London map and the growth.
- **Layers:**
  - the existing rail by service (National Rail, each tube line, Overground, Elizabeth line, DLR, trams, stations);
  - HS1 and HS2;
  - the Green Belt and AONB;
  - topography with hill shading, 3D relief and 3D buildings.
- **Built to be combined with the London map:**
  - MapLibre GL JS 6.13.0 and the OpenFreeMap Liberty style, as in `incubator/google-map-live`;
  - the same language contract (`langStorageKey` `loopCityMap.uiLanguage`);
  - every layer id starts with `lc-`;
  - no imports from outside its own folder.
- **Copied from `incubator/google-map-live`:** three files (`osm_basemap_themes.js`, `terrain_local.js`, `terrain_worker.js`) and its terrain picture, credited in `SOURCE.md`. They can become `shared/` imports.
- **`serve.py`** is a small local test server only; the site does not use it.
- **Tested** from a local server in Chrome and Edge. Not yet tested on GitHub Pages or inside the site's frame.
- **Touches only:** `incubator/loop-city-real-map/`, one item in `incubator/catalogue.json` (placed after Loop City wool bands) and `assets/catalogue/loop-city-real-map.webp`.
