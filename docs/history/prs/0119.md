## 改了什么 · What changed

打开主程序的 `01 Loop City` 不再计算。它显示一份在电脑上算好并存下来的结果，任何设备都一样快；按「运行百年」时才载入引擎，自己算一次。

Opening `01 Loop City` no longer computes anything. It shows a result grown once on a desk and stored small; the engine is loaded only when Run is pressed.

| | 之前 · Before | 现在 · Now |
|---|---|---|
| 打开到看见结果 | 十几秒准备，再算 1 到 3 分钟 | 0.5 秒加下载（先取 1.7 MB） |
| 模拟手机上主程序占用内存 | 760 MB 起，运行中更高 | 约 300 MB（其中外壳约 180 MB） |
| 拖时间轴每年 | 约 0.1 秒 | 7 到 40 毫秒 |

- **存了什么**：城市生长逐年精确（2025 年整图加每年变化的格子，1.2 MB）；黏菌每 5 年一张图，中间年份按比例叠加（共 2.1 MB）；干道、单元、车站、铁路的线。全部从孵化区页面自己的画布读出，这里不含模型知识。
- **自己运行**：「运行百年」照旧，按下后载入引擎（十几秒），算完可点「回到发布的结果」。参数滑块在引擎载入后出现；之前显示发布结果所用的参数值。
- **重新发布**：`node modules/01-loop-city/tools/publish-result.mjs`。孵化区的算法或配色改了以后要重新发布，否则打开看到的仍是旧的那次运行。面板上写着结果的运行日期；`node --test` 在孵化区页面比结果新时给一行提醒，不算失败。
- 没有发布结果或浏览器打不开时，退回原来的做法（打开即载入引擎）。
