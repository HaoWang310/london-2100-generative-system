## 说明 · Description

## 改了什么

打开张量场时原来依次出现：白底 → 黑底 → 一张默认的彩色图 → 「第 1 步」。在手机上白底会停很久（模拟手机约 12 秒），看起来像频闪。

原因：深色主题由引擎设置，而引擎要等场地数据读完才启动；流程模式的脚本又晚一步到，把画面重置一次。

现在：
- **第一帧就是该有的颜色**。单独打开时用上次选的主题，第一次为深色；从伦敦地图打开时跟随地图，底是透明的。规则和 `app.js` 的 `boot()` 相同。
- **画布中间显示「正在载入场地…」**，等引擎和流程模式都画好了才揭开。电脑上两块面板也一起等；手机上收起的底部卡和「显示」按钮不变。载入失败时，提示显示在屏幕中间。
- **三个脚本**（`app.js`、`env_anim.js`、`process.js`）**和场地数据同时下载**，执行顺序不变。

## 影响范围

只改了 `incubator/tensor-studio/index.html` 和 README。`app.js`、`scripts/`、算法和主程序外壳都没动。电脑端和手机端都受影响（同一段代码）。
