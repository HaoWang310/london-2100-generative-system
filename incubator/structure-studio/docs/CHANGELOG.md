# 版本记录

## v0.4（2026-11-17）

- 保存输入：从张量场取来或载入的结果自动存在本机浏览器（IndexedDB），左侧"场地"卡新增"输入"下拉（内置示例 · 车站 P2 + 已保存的各份）；每份记着自己的结构参数，打开 09 时回到上次用的那份和参数，不用再跑张量场。
- 改名、删除（点两次确认）、"导出快照"（下载当前输入 + 名字 + 参数，"载入文件…"可原样恢复）；同一路网重复取来不重复保存；浏览器不能保存时（无痕窗口等）给出提示。
- 仓库里的默认示例与自动测试不变（车站 P2）；结构设计定稿后再替换。
- "只看张量场结果"开关（场地卡）：平面图只画场地、水系、张量场道路（主干 / 贯通 / 支路分级）、路口、吸引点（红圈），可叠"张量场方向线"；顶部提示路数、长度、路口数。切到三维时自动关闭。
- 平面图改成 AADRL 风格，配色参照布达佩斯城市地图、底色为黑：农田浅鼠尾草绿 #e1e6cf 纯色（去掉条纹）；走廊白色加发丝描边；水体灰蓝；建筑黑色剪影；室内道路白色细线；场地外环境压成细灰线；只用红色一种强调色。
- 红线：结构场地外缘（含跨水部分）画红色点划线；种植塔画红圈，主线改细红虚线。红线、室边线、主线都是屏幕空间矢量，缩放时线宽不变。
- 色卡（右侧"配色"）：8 套渐变（青到紫、日落、酸性绿、冰蓝、粉到酒红、光谱、青、灰到橙），地块按离核心距离渐变 + 顺张量场的白色流线（AADRL / ZHA 式），选择会被记住；流线按场地缓存成蒙版，换色约 1 秒内完成。
- 室标签只在悬停时显示（提示框 + 白色描边），选中的室描红边。
- 新图层"图纸元素"：英国国家网格整百米坐标十字、比例尺、指北针；导出的平面 PNG 一并带上。三维材质同步换成低饱和配色。

## v0.3（2026-11-17）

- 界面与张量场工作室、伦敦地图统一：全屏视口；左侧浮动参数栏（生成流程五步，可展开 / 收起，整栏可折叠）；右侧浮动显示栏（视图、镜头、图层、图例、统计、导出、说明）；底部室卡片条；顶部状态提示。
- 平面图在两侧面板之间的空白区域居中。
- "从张量场工作室取结果"：在 09 里直接打开张量场工作室，选场地、跑完全流程后点"用这个结果"，结构就在这条路网上重新生成（读张量场工作室公开的 roadNet() 与张量场，不改它的文件）；"载入文件…"仍可载入导出的快照。
- 更快：改参数后的重算从约 4–5 秒降到约 1.5–2 秒——主线与种子无关、按参数缓存；水边 / 铁路距离场缓存在场地上；室的有符号距离只算窄带；三维网格只在切到三维时才生成；平面视图下不做三维高亮；拖动时立即显示"生成中"。
- 中英文：面板上有中文 / EN 切换；在目录里打开时隐藏自己的切换，跟随主程序的语言（l2100:lang 消息 / 本地存储）。
- 两侧面板可拖动内边缘改变宽度（左 300–640 px，右 200–440 px；双击恢复默认；键盘左右键也可调），宽度记在本机浏览器里。
- 室卡片条默认隐藏：底部"室列表"按钮或右侧图层开关打开，条上"隐藏"收起；卡片文字不再被截。
- 界面强调色统一为白色（当前步骤、步骤编号、开关），不用蓝色。

## v0.2（2026-11-17）

- 结构架在地面之上：走廊在整个场地外轮廓内连续生成，跨过水面、铁路缝和洞不再截断，只在场地外轮廓处切断；跨越段在三维里是 1.2 m 厚的架空桥面，下面按"桥下柱距"（默认 45 m）放成对的柱子。
- "避开水面"改为开关，默认关闭（打开后才把大半在水上的走廊删掉、两室合并）。去掉"最大桥跨"。
- 平面图改成矢量：土地、农田条带、退线带、水体、溪流、结构轮廓都按矢量画，去掉锯齿和黑边；结构带投影，跨水 / 跨铁路处压一层淡色。
- 建筑和农田离水边、铁路缝至少一个退线距离。
