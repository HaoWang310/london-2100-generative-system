# Tensor Studio · 张量场工作室

在线：https://haowang310.github.io/london-2100-generative-system/incubator/tensor-studio/

由等高线、全年风场与吸引点叠加成张量场，从锚点生长道路（v8 引擎，苹果风格界面）。
界面与伦敦地图（google-map-live）统一：**左侧浮动控制面板**（参数、预设、高级参数，可收起），**右侧显示面板**（模式、场分析、张量场、道路、显示开关、浅色 / 深色、暂停与显示结果）。平面图自动适配两块面板之间的区域。
直接打开时运行原版的 **车站 P2 示例**（与 v8 单文件版结果一致：193 条道路、29 处涵洞、2 处环形广场）。

## 第 5 步：三种节点（v8.11）

流程模式里吸引点只能手动放置。先点选一种节点，再在地图上**单击**放置（拖动地图不会放点）；拖动节点可移动，右键删除，"全部清除"清空。下面的滑块调节**所选种类**的吸引强度，三种各自保存（引擎里的 `KPULL`）。地图上三种节点颜色和形状不同：主节点蓝色大圆环、次节点青色小圆点、边界节点紫色方块；圆点随吸引强度变大，虚线圆是影响范围。第一次进入第 5 步时，场推荐的点会转成可编辑的手动点。

| 节点 | 作用 |
|---|---|
| 主节点 · 环形广场 | 影响约 230 米，周围道路绕成环形广场并向外放射 |
| 次节点 · 街区中心 | 影响约 140 米、力度较弱，附近道路微微弯向它，不形成广场 |
| 边界节点 · 入口广场 | 吸附在场地边界上，形成半圆形入口广场，影响约 340 米 |

Shift / Alt + 双击的快捷键仍然可用。自由模式保留原来的全部布局方式。

## 分析场动画（v8.9）

流程模式第 2 步，点开每张分析图都会循环播放它的粒子动画（`scripts/env_anim.js`，只是显示，不影响计算）：

| 图 | 动画 |
|---|---|
| 高程 | 水位上升：等高线从最低处逐条亮起，光点沿已亮的等高线流动，地形底色随之淡入；左上角显示当前水位 |
| 汇水 | 雨水落在场地上顺坡往低处流，雨滴汇到一起的地方变亮变粗，汇水路径自己画出来 |
| 夏季通风 | 夏季风粒子吹过场地：通风好的地方快而亮，被水体和坡地挡住的地方慢而暗 |
| 冬季冷风 | 只放北、东北、东方向的冷风粒子，冷风强处底色逐渐压暗 |
| 气候舒适 | 夏季风（绿）和冬季冷风（紫）先后吹过并交叉淡出，叠成舒适度图；最舒适的三处亮起圆圈，标为"广场候选"（目前只是展示） |

"播放分析"依次播放五张，每张一个循环，最后一张继续循环。深色主题带光晕。系统开启"减少动态效果"时只显示静态图。

## 环境参与道路生成（v8.8，第二期第一轮：方向与约束）

第 2 步看到的五张分析场，现在有四张直接参与道路计算（气候舒适度留给第二轮，用来控制疏密）：

| 因素 | 作用 | 位置 |
|---|---|---|
| 汇水 | **蓝绿走廊**（硬约束）：主要汇水路径两侧留出走廊（默认 30 m 宽），道路不沿走廊内部走，只能近似垂直（≥30°）地跨过，跨处记为涵洞；走廊旁的道路沿走廊方向（滨水路） | 第 3 步 `gOn` `gW` `gQ`，第 4 步 `wG` |
| 夏季通风 | 夏季风能大的方向、风吹到的地方，道路顺着风走（通风廊道） | 第 4 步 `wSum` |
| 冬季冷风 | 冷风（N / NE / E）强的地方，道路横切冷风（挡风） | 第 4 步 `wWin` |
| 高程 | 顺等高线（原有） | 第 4 步 `wC` |
| 洪水风险 | 避让 + 顺流排水（v8.5 原有） | 第 3、4 步 |

走廊由 `scripts/env_fields.js` 的 `corridors()` 计算（v8.10 起用绝对门槛：上游汇水面积 ≥ 2 公顷的连通路径，短于 100 m 的去掉，按半宽扩展；若走廊仍超过土地的 12%，门槛自动提高。这样伦敦平坦场地不会出现满场的平行假汇水线），在 `app.js` 里并入水道区（`inZone` / `streamAngle`），所以生长、延伸和收尾各阶段都遵守同一条规则。夏季 / 冬季的权重用 `env.stats` 里各方向的季节风能和每个方向的来风面（`dirs[k].S`）。

## 流程模式（v8.7，默认）

打开后不再直接给出结果，而是按 8 步展示生成过程：**选场地 → 看环境 → 定约束 → 建张量场 → 放吸引点 → 长主路 → 长次路 → 评价出图**。

- 左侧面板一次只展开当前一步，只显示这一步的参数和说明；做完的步骤折叠成一行摘要。
- 改动某一步的参数后，后面做过的步骤标为“需重算”。
- 地图按步骤显示中间结果：第 2 步依次播放五张分析场，第 3 步显示洪水避让后的土地，第 4 步显示流线（吸引点此时还不参与），第 5 步加入吸引点后流线弯曲。
- 第 6、7 步的生长逐帧记录。底部时间轴可以播放、暂停、调速（慢 / 中 / 快），也可以拖动回看；拖动时生长会暂停，按播放后先回放已记录的部分，再继续生长。蓝色刻度是主路与次路的分界。
- “播放全流程”从第 1 步自动走到第 8 步。流程模式不显示图册预设，参数都在各步骤里设置；预设仍在自由模式中（点预设会把参数填进各步骤）。
- 第 8 步显示路网指标，并与上一次结果对比，也可以从这里导出 GeoJSON 和 PNG。
- 面板顶部可以切换到 **自由模式**（v8.6 的完整参数面板，打开即是结果）。选择会被记住。

## 洪水风险（v8.5）

- 数据：英国环境署当前洪水风险，**地表水（RoFSW）与河流和海洋（RoFRS）逐格取较高等级**，25 m 栅格（`assets/flood_risk/`，与伦敦地图同一份，© Environment Agency，OGL v3）。覆盖国家网格 E 460–600 km、N 110–250 km：全伦敦与车站 P2 示例。
- 作用（左侧「常用参数 → 洪水风险」）：
  - **避让**：默认高风险区（≥ 3.3 %/年）不长路，可改为中及高风险区或不避让；避让区边界当作岸线，道路沿它走或在它前面停下。
  - **顺流排水**：中、低风险区里道路顺着水流（坡度方向）走，权重滑块默认 40。
  - 关掉「洪水影响道路」即回到 v8 原结果。
- 指标：落在中、高风险区的道路长度与占比，场地内各等级面积。车站 P2 最终方案（3.6）：高风险区里的道路从 5.41 km 降到 0.50 km，中高风险占比 17.6 % → 5.5 %。
- 右侧「显示 → 洪水风险」开关显示风险图层（虚线为避让区边界）。

## 分析场（v8.6，道路生成逻辑第一期）

设计见文档《Tensor Studio 气候–地形–风–洪水道路生成逻辑设计》。第一期只做分析，还不改变道路：右侧「分析场」可切换查看

- **高程**：车站 P2 由 1 m 等高线重建（在等高线上平均误差 0.07 m），伦敦选区用 OS Terrain 50；叠加西北光照山体阴影。
- **汇水**：填洼后的 D8 汇流面积（对数）。验收：汇水最强的 3 % 格子中 66 % 落在 EA 低风险及以上区域，全场为 31 %（2.1 倍）。
- **夏季通风**：6–8 月各风向风能（占比 × 风速²）按各方向吹进场地的强弱分布；以西风、西南风为主。
- **冬季冷风**：12–2 月北、东北、东向风能；以北风为主。
- **气候舒适**：0.6 ×（1 − 冷风）+ 0.4 × 通风。

日照暂不纳入。计算在 `scripts/env_fields.js`（纯函数，`node scripts/test_env_fields.mjs`）。

## 以后接到伦敦地图（google-map-live）

两边只通过一个对象通信，互不引用代码：地图页设置

```js
window.__TENSOR_SITE_INPUT__ = { ring, features, elevation, lang, close, fail };
```

再用同源 iframe 打开 `../tensor-studio/index.html`。本页检测到它，就用 `site_builder.js` 为该选区生成场地，
顶栏出现「返回伦敦地图」和「现有建筑：清除重建 / 保留绕开」。`?keep=1` 表示保留建筑。
接线步骤写在 `integration/google-map-live-hook.js` 开头。

## 限制

- 选区跨度 ≤ 3.6 km，面积 ≥ 2 公顷。
- 风暂用 Luton 一年（未按选区取风）；原版按 Global Wind Atlas 的局部风速未带过来，现仅按风吹入地块的衰减（L = 600 m）。
- 地形 OS Terrain 50（50 m）；伦敦大多平坦，平均坡度 < 0.8 % 时等高线权重按比例减弱。
- 图册、视频与原始脚本（v8 单文件版的「图册与视频 / 原始资料」）未放入本文件夹。
