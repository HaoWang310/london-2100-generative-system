# London 2100 · VR / MR

在线：https://haowang310.github.io/london-2100-generative-system/incubator/vr/

London 2100 生成式城市系统的 VR / MR 设计文件夹，目标设备是 **Meta Quest 3S**。用 Quest 自带浏览器打开即可（WebXR），不需要安装 app。

- 这个文件夹**只读场景文件**，不引用其他 app 的代码，格式见 [`docs/SCENE-FORMAT.md`](docs/SCENE-FORMAT.md)。所以可以和 Tensor Studio 同时开发：那边继续改算法，这边改三维和交互，互不影响。
- 它和其他 app 在同一个网址下，以后可以直接读取正在运行的 Tensor Studio，不用再导出文件。

## 第一步：一个入口 · 整个伦敦 · 点桌子打开面板（v0.54）

- **一个入口**：从 app 目录打开 VR（`incubator/vr/`）直接进入展厅 + 伦敦地图（带地图控制面板，即 map.html）；Hydro Lab 等静态场景仍用 `?scene=…`
- **桌上默认是整个大伦敦**（约 72 km，app 里伦敦地图的样式和图层）；远看只有底图和水系，握住地图 + 右摇杆放大到几公里内出现三维建筑。从地图 app 里按 VR 进入时仍是当前街区（约 3 km）
- **点桌子 →「面板」→ 控制面板**：射线指到桌面上，桌沿亮起；短按扳机，桌沿靠你这边上方出现「☰ 面板」；点它，地图控制面板出现在桌沿上方、你的右前方，面向你（可拖动，「收起」关闭）。面板开着时再点一下桌子也会收起。长按扳机仍是拖动地图
- 左手上的「面板」按钮去掉了；按下左摇杆仍可快速开关面板


## iPad / iPhone 上的三维预览（v0.53）

- 预览可以用手指操作：单指旋转；双指捏合缩放；在地图预览里双指拖动平移（相当于鼠标滚轮和右键拖动）
- 在 iPhone / iPad 上，「在 Quest 上打开」卡片写明这些设备不支持 VR（Safari 没有 WebXR），旁边就是三维预览
- 只在手指操作时生效，电脑上的鼠标操作不变

## 统一到英国国家网格（v0.52）

- VR 里所有坐标改成**英国国家网格（EPSG:27700，米）**，和主程序、Tensor Studio、结构工作室一致：`本地米 = 国家网格 − 起点`，x 向东、y 向北
- 以前用的是 Web Mercator × cos(纬度)，在伦敦和国家网格差约 **1.5° 的转角**，离起点每 1 km 偏约 25 m；现在 OSM 建筑、Tensor Studio 道路（GeoJSON / 场景文件）、Hydro Lab 地形放在一起能对齐
- 移动加载的 OSM：每块瓦片用一个小网格精确换算到国家网格，地面图、建筑、树、车在瓦片里插值放置（z14 误差小于 1 cm），离英国很远的整球视图自动退回近似换算
- 地图 → VR：截图的四个角按国家网格放，建筑同一套坐标
- Hydro Lab 场景重新生成：300 m 网格直接铺在国家网格上（`crs: EPSG:27700`，`origin` 是格子 (0, 0) 中心的国家网格坐标）
- 换算公式是 `shared/geo-core/epsg27700.js` 的副本（`src/epsg27700.js`），这样 VR 文件夹以后打包 APK 也能单独用；`node incubator/vr/tools/check-geo.mjs` 检查两份是否一致
- 车站 P2 场景用最新的 Tensor Studio（v8.45）重新导出，道路换成它的**正式路网**（清理过的街道、真实宽度、三级道路），和 Tensor Studio 的 GeoJSON、结构工作室一致；以前是 v8.6 时导出的旧道路
- 外观和操作没有变化

## 右摇杆上下：抬头低头（v0.51）

- 展厅里**右摇杆往上推抬头、往下拉低头**，和左右转身一样平滑（最快约每秒 60°），最多上下各 60°，松手后保持在当前角度；**按下右摇杆**慢慢回正到水平
- 去掉了「向下拉瞬间转身 180°」，不会再误触突然转到背后
- 防误触：主要往上下推时不会跟着转身，主要往左右推时不会抬头低头
- 模拟器键盘：**R / F 抬头 / 低头**（Q / E 转身、WASD 走动）
- 做法：头显和两个手柄的位置都绕你眼睛的左右轴一起转，所以抬头低头后用手柄指屏幕、抓地图仍然对得上
- 提醒：戴头显时直接抬头低头就可以，用摇杆抬头低头会让地平线倾斜，容易晕；这个功能主要给坐着和模拟器里用

## 平滑转身（v0.50）

- 向下拉转身 180° 仍是瞬间转（v0.51 去掉了，右摇杆上下改成抬头低头）

## 在展厅里走动、点屏幕（v0.28）

- **左摇杆 = 走动**：在展厅里（VR 和 MR）推左摇杆，人朝你看的方向走（侧推 = 横移），速度约 1.8 m/s；只能在展桌和屏幕之间走，不会穿过桌子或走出屏幕圈。进入时你站在离桌子中心约 2.2 m 处，往前有地方走
- **走动的做法**（v0.30）：不是移动你，而是把展厅、地图和你放在空间里的面板一起往反方向移，所以在所有浏览器和模拟器里都一样能走
- **电脑上的模拟器**（v0.29）：也可以用键盘 W A S D 或方向键走动（先点一下页面让它获得焦点）；摇杆在第 2、3 轴或第 0、1 轴都能读到
- **地图固定在桌上**：左摇杆不再把地图抬高 / 放低；握持键抓地图只会在桌上**滑动、转动**伦敦（盘子不动，下面的城市在移），双手可以缩放，但地图不会离开桌面；静态场景（方形模型）只能转动。Y 键把地图复位
- **点屏幕**：右手射线指向一块屏幕，屏幕会变亮；按扳机，它在你面前 1.2 m 放大显示（1.4 m 宽）；再按一次扳机（或指别处按）关掉
- 1:1 漫游（B 键）时左摇杆仍是在城市里走

## 沙盘展厅（v0.21）

进入 **VR 或 MR** 后，伦敦圆盘放在一张展桌上，周围是一个 Zaha Hadid 风格的流线展厅。代码在 `src/hall.js`（WebGL2，不用外部库），`src/xr_view.js` 只是把它画在地图后面。
- **壳体**：墙面从地面升起、向内收、带扭转，连续卷成天花，中间是圆形天窗；壳体上的竖向凹槽每几道是一条发光线
- **展桌**：白色流线体从地面"长"出来，圆盘放在桌面上（桌高 0.9 m）。VR 里圆盘半径从 0.45 m 加大到 **0.7 m**；Y 键把地图放回桌上
- **漩涡顶棚**：沙盘上方 3.2 m 悬吊一片发光薄膜，像水流向沙盘汇聚（参考 Winton 展厅的悬吊发光顶棚），由 6 根钢索吊着
- **地面**：白色地坪上的发光流线绕着沙盘流动；桌子后面 3 块弧形屏幕（水文基底 · 2100 洪水情景 · 多尺度生成系统）；两侧各一张 Zaha 长凳（`assets/zaha-bench.glb`）。v0.32 起屏幕从 7 块减到 3 块，长凳从 4 张减到 2 张
- **氛围**跟着 app 的光照：白天 = 白色；夜晚 = 青色光带。网址参数可以固定：`?hall=day`、`?hall=night`、`?hall=violet`（紫光展陈），`?hall=0` 关掉展厅
- 展厅出现在你面前（进入 VR 时朝向的方向），你站在桌边；1:1 漫游时展厅隐藏
- **MR 也进展厅**（v0.27）：MR 和 VR 一样，周围是展厅、展桌、长凳和屏幕，圆盘 1.4 m（以前 MR 只看真实房间、圆盘 0.45 m）
- 性能：展厅约 7.8 万个三角形、20 次左右绘制；所有发光都画在贴图里，不是真实灯光

## 天气、光照、阴影、树、小车（v0.18）

这些在 app 里是额外画在地图上的，VR 截取的地面里没有，所以 VR 自己用三维做了一遍，并**跟着 app 面板上的按钮和开关**（`src/app_state.js` 每 0.3 秒读一次 app 页面）。光照和天气的颜色、太阳方向直接用 app 自己的 `scripts/map_atmosphere.js` 里的预设（只读导入），所以和 app 一致。
- **光照**：黎明 / 白天 / 黄昏 / 夜晚 / 实时（按地图中心的真实太阳位置）。改变太阳方向、光的颜色和强弱、天空颜色；地面的颜色变化来自 app 样式本身
- **天气**：雨（雨丝）、雪（飘落的雪花）、雾（越远越白）；桌面模式在圆盘上方的一个圆柱里，1:1 漫游时在你周围
- **建筑阴影**：按太阳方向投到地面，重叠处不会更黑；夜晚没有，雨雾雪里变淡（与 app 相同的系数）
- **绿化树木**：在 OSM 的公园、林地、草地里随机种树（每块瓦片最多约 2200 棵，只在街道级）；与 app 一样只是视觉示意
- **街道小车**：沿主要道路行驶、靠左，桌面模式下按比例放大一些以便看见
- 没有 app 时（`index.html`）可以用 `?fx=trees,cars,rain,night` 这样的参数试效果（可选：dawn/day/dusk/night、clear/fog/rain/snow、trees、cars、noshadows）
- 修复：圆盘下的底色原来是一块超大的平面，深度精度不够时会盖住一半地图（也会引起闪烁），现在只画在可见的圆周围

## 移动加载（v0.7，简单版）

像网页地图一样：只加载你看着的那一片，移动到哪里就加载到哪里，远处不显示。
- 数据：OpenFreeMap 的 OSM 矢量瓦片（z14，伦敦一块约 1.5 公里），每块画成地面贴图（道路、水面、绿地）并把建筑按 `render_height` 拉伸。代码在 `src/stream.js`，瓦片管理在 `src/xr_view.js` 的 `updateTiles`
- **桌面沙盘**：桌上是一个圆形区域（半径 0.45 m）。抓住模型拖动，就像拖网页地图，新的瓦片自动加载，离开范围的自动卸载；双手缩放改变看到的范围（最大半径 2.5 公里）
- **1:1 漫游**：只加载你周围 1.5 公里，边走边加载
- 电脑预览：右键拖动平移，滚轮缩放
- 同时最多 40 块瓦片（约几万栋建筑），保证 Quest 3S 流畅
- **从 `map.html` 打开时，地面和 app 地图一模一样**（v0.12）：`src/map_painter.js` 在地图页面里用 app 当前的样式（主题、标注、开着的图层）另开一个隐藏地图，按瓦片渲染成贴图替换上去；建筑颜色也取 app 的设置。每块先显示简化样式，app 样式画好后替换，左下角会写「几块已用 app 样式」。换了主题或图层，退出 VR 再进一次即可
- 直接从 `index.html?scene=osm:…` 打开（没有地图）时，地面仍是简化的 OSM 样式

### VR 里的 app 控制面板（v0.15）

`map.html` 的 VR 里有和 app 一样的控制面板（`src/app_panel.js`）：
- 内容**每次都从 app 页面读取**：视图、光照、天气、颜色主题、显示开关，以及分析图层的开关，连同哪个选中、哪个不可用。app 以后加了按钮，VR 里会自动出现
- 在 VR 里按一个按钮，等于**点 app 里的同一个按钮**，用的是 app 自己的代码，app 一行不改。按完约 0.7 秒后，VR 的地面按新的样式重画，建筑颜色也跟着 app 变
- 电脑上：面板在三维视图右侧，用鼠标点；顶栏「面板」按钮可以收起 / 打开。进入 MR / VR 后它自动隐藏（模拟器里不再挡住头显画面），退出后再出现
- 头显里（v0.23）：进入 VR / MR 时面板**默认收起**，不挡视线。左手上方的帮助卡片下面有一个「☰ 面板」按钮，右手射线指着它按扳机就打开；面板拖动条右边有「收起」按钮。左摇杆按下也可以打开 / 收起。打开后面板在**左手上方**（或你上次放在空间里的位置），转向你；用**右手射线指着按钮、按扳机**点击（手势：捏合）。射线指到面板时会停在面板上
- **移动面板**（v0.19）：面板下方有一根拖动条。射线指着它，按住扳机或握持键（手势：捏合）拖到任何地方，松开就固定在空间里，并始终转向你。也可以用握持键抓住面板本身。拖动时右摇杆上下 = 推远 / 拉近，左右 = 缩小 / 放大。离开 VR 再进来，面板还在原来的位置
- **左摇杆按下**：打开 / 收起面板（打开时回到上次的位置：左手上，或你放在空间里的地方）
- 目前 VR 里不显示：建筑阴影、绿化树木、街道小车（app 用特殊的 WebGL 图层画的），以及三维城市视图（VR 自己拉伸建筑）。搜索框需要 VR 键盘，之后再做

## 从伦敦地图进入 VR（v0.4 起）

打开 **`map.html`**：https://haowang310.github.io/london-2100-generative-system/incubator/vr/map.html

**打开就直接是 VR 界面**（默认是上面的移动加载；地图在后台加载），方便反复检查：
- `map.html?at=51.5007,-0.1246,16`：指定位置（纬度、经度、缩放）
- 不写 `at`：用上次的位置；第一次用伦敦市中心
- 每次打开后网址会自动带上当前位置，刷新就是同一个场景
- VR 界面右上角「地图」：回到地图，地图会跳到你在 VR 里最后看的位置；调整好再按右下角 VR
- `map.html?mode=capture`：用截图模式（当前地图画面和图层 + 建筑，一块固定区域）
- `map.html?map=1`：先显示地图

它把伦敦地图（`../google-map-live/`）原样嵌进来，地图的所有功能照常可用，**地图主程序一行都没改**。VR 按钮在这个外层页面上（右下角坐标上方）：
1. 在地图上照常设置：搜索地点、开图层、选主题和光照、画场地边界……
2. 按 **VR**：地图会短暂转成正北朝上的平面，截下当前画面（开着的图层都在里面），再把地图已经载入的 OSM 建筑按 `render_height` 拉伸成体块。相机随即回到原来的角度
3. 三维沙盘覆盖在地图上：电脑上可以预览，Quest 上按「进入 MR」放到桌上，按 B 走进街道
4. 按「关闭」回到地图，所有状态都还在

地图缩得比 15 级更远时，VR 会以当前中心临时放大到 15 级（约 4 公里范围）再截图，否则建筑在桌面上小得看不见；地图的视角事后照样还原。如果地图还是没有载入建筑，VR 会直接从 OpenFreeMap 读取中心 3 × 3 个 z14 瓦片的 OSM 建筑。VR 里的地面是一张截图，在 VR 里不能改图层；要改就关掉 VR，在地图上改完再按一次。

外层页面怎么拿到地图：`src/map_bridge.js` 在地图页面自己的环境里再导入一次同一个 MapLibre 模块（拿到的是同一个 Map 类），临时包一下 `Map.prototype.fire`，等地图触发下一个事件时取得地图对象，然后马上还原。如果以后地图换了 MapLibre 的加载方式，只需要改这个文件。

另外，`?scene=osm:纬度,经度,半边长米` 可以不经过地图，直接从 OpenFreeMap 读取 OSM 数据生成场景（`src/osm.js`，顶栏菜单里有伦敦市中心）。

## 现有场景（v0.2）

- `index.html`：打开后显示 **Hydro Lab · 伦敦 70 公里**，顶栏的菜单可以切换场景：
  - `data/hydro-lab-70km.scene.json`：London map · Hydro Lab 的 70 公里研究圈，300 m 网格。OS Terrain 50 地形（高程默认放大 12 倍，伦敦太平了）、EA 洪水风险（河流海洋与地表水的较高等级）、汇水网络（上游面积 ≥ 1 / 10 / 100 / 1000 km²，颜色由浅到深）、大伦敦边界和 70 公里圈。用 `tools/build-scene-hydro-lab.py` 从 Hydro Lab 自己的资源文件生成。
  - `data/station-p2.scene.json`：Tensor Studio 车站 P2 示例按「立即生成」得到的 145 条道路、地形和洪水风险。
  - 换场景：`?scene=别的文件.json`，或者直接把场景文件拖进页面。英文界面：`?lang=en`
- 电脑上：三维预览。拖动旋转，滚轮缩放，右键平移。可以开关洪水风险、汇水网络、边界或现有街道，调高程放大倍数。
- Quest 3S 上：出现「进入 MR」按钮。
  - **MR 桌面沙盘**：开彩色透视，模型约 90 cm 宽，放在面前的桌子上
  - 握持键或捏合手指抓取模型；双手同时抓可以缩放、旋转
  - 右摇杆：旋转和缩放 · 左摇杆：升降
  - **A** 洪水风险 · **B** 在桌面和 1:1 漫游之间切换 · **X** 汇水网络（Tensor Studio 场景里是现有街道）· **Y** 把模型放回面前
  - **1:1 漫游**：站在真实尺度的地面上，脚下跟着地形起伏；左摇杆行走，按住越久越快（70 公里的场景里最快约 2,000 m/s），右摇杆每次转 30°
  - 左手上方有一张操作说明卡

完全不依赖外部库：`src/xr_view.js` 直接用 WebGL2 + WebXR 写成，地形、道路和底座的几何都由它生成。

头显部分在一个模拟的 WebXR 环境里跑过（抓取、双手缩放、按键、漫游都没有报错），但还没在真机上测过。

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` | 入口：载入场景，打开三维视图 |
| `src/xr_view.js` | 三维视图、WebXR 会话、手柄和手势交互、几何生成（`buildTerrain` / `buildRibbons` 是纯函数） |
| `src/scene.js` | 检查场景文件，并转换成视图需要的只读接口 |
| `map.html` | 嵌入伦敦地图 + VR 按钮（地图本身不改） |
| `src/map_bridge.js` | 从嵌入的地图页面里找到 MapLibre 地图对象 |
| `src/from_map.js` | 截图、建筑、打开视图 |
| `src/osm.js` | OpenFreeMap 矢量瓦片解码、地面贴图、建筑体块 |
| `src/stream.js` | 移动加载：按瓦片读取、绘制、拉伸建筑 |
| `src/map_painter.js` | 用 app 地图自己的样式渲染 VR 地面瓦片 |
| `src/app_panel.js` | 从 app 页面读取控制面板，画成 VR 面板，按钮转发给 app |
| `src/app_state.js` | 读取 app 当前的光照、天气和显示开关（用 app 的预设） |
| `src/features.js` | 每块瓦片的树和小车路径 |
| `data/*.scene.json` | 场景；`data/scenes.json` 是顶栏菜单的列表 |
| `tools/build-scene-hydro-lab.py` | 从 `../google-map-live/assets` 生成 Hydro Lab 场景（需要 numpy 和 Pillow；参数是网格倍数，默认 6 = 300 m） |
| `tools/export-from-tensor-studio.mjs` | 无界面运行 Tensor Studio，导出场景（在本文件夹里运行） |
| `docs/SCENE-FORMAT.md` | VR 与生成系统之间的数据约定 |
