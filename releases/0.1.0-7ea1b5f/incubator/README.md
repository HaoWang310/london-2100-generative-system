# incubator · 孵化区

合作者已有的独立 app 放在这里，每个 app 一个子文件夹，保留原有 `index.html`，各自独立运行、互不影响。
准备融合进统一系统时，再在 `modules/` 中为它写适配模块。

Existing standalone apps live here, one folder each, untouched. Each is deployed
to `/incubator/<app>/` on GitHub Pages. They are integrated later through an
adapter module in `modules/`.
